# SOP-04 — Deliver

## Goal
Render the validated `TestPlan` JSON into a professional Markdown document + JSON export.

## Inputs
- `.tmp/testplan_{key}.json`

## Tool logic
1. Render Markdown with a fixed layout:
   - Header table: Plan ID, Source Jira, Generated at, Author, Version, Model.
   - §1 Scope (in/out/assumptions), §2 Test Strategy, §3 Test Data, §4 Environment.
   - §5 Scenarios — one subsection per scenario; each test case rendered as a row: ID, preconditions, steps, expected result, test data, priority, automation candidate, traceability.
   - §6 Traceability Matrix table (requirement → case IDs).
   - §7 Low-Confidence Notes.
   - Footer: generated by the AI Test Plan Agent (BLAST pipeline).
2. Write files to `output/`:
   - `test_plan_{key}.md` — the deliverable.
   - `test_plan_{key}.json` — machine-readable export.
3. Return both paths (the UI shows the Markdown inline and offers a download button).

## Edge cases
- Empty lists (out of scope, assumptions, test data) render as "None stated." — never omitted sections.
